# Week 1 — First Wins: GitHub, VS Code & the Terminal

## Quick Start

This week is for beginners.
No experience needed.

| What             | Details                                                                                  |
| ---------------- | ---------------------------------------------------------------------------------------- |
| Who is this for? | Everyone learning together                                                               |
| Operating system | Ubuntu Linux                                                                             |
| Time needed      | About 1 hour a day (Monday to Friday)                                                    |
| Goal by Friday   | Have a live GitHub profile, know VS Code basics, and move around folders in the terminal |

## What You Will Learn

By the end of Week 1, you will be able to:

1. Set up and update your GitHub profile.
2. Use VS Code with confidence.
3. Run basic terminal commands without fear.

1. Start with [Day 1](./day1.md) and continue to [Day 5](./day5.md) in order.
2. On [Day 3](./day3.md), make a command cheat sheet you can reuse.
3. On [Day 5](./day5.md), test yourself and note what to practice again.

## How to get deeper understanding (without overload)

Use this quick pattern each day:

1. Learn: read and follow the steps once.
2. Repeat: close the page and do the same task from memory.
3. Explain: write 2-3 lines on why the command/tool exists.
4. Apply: use it in a tiny real task (rename a file, create notes, open in VS Code).

If you can explain it simply, you understand it.

## Small daily stretch (optional)

- Add one extra command or shortcut to your cheat sheet each day.
- Teach one thing to a friend or family member in under 60 seconds.
- End each day by typing one command from memory and predicting its output before pressing Enter.

## Week 1 quick reference

| Command              | What it does          |
| -------------------- | --------------------- |
| `pwd`                | Show current location |
| `ls`                 | List files in folder  |
| `ls -l`              | List with details     |
| `cd foldername`      | Enter a folder        |
| `cd ..`              | Go up one level       |
| `cd ~`               | Go to home folder     |
| `mkdir name`         | Create a folder       |
| `touch file.txt`     | Create empty file     |
| `cp a.txt b.txt`     | Copy a file           |
| `mv a.txt b.txt`     | Rename or move a file |
| `rm file.txt`        | Delete a file         |
| `tree folder/`       | Show folder tree      |
| `code .`             | Open VS Code here     |
| `sudo apt install X` | Install software X    |
| `Ctrl+Alt+T`         | Open terminal         |
| `Tab`                | Autocomplete          |
| `Ctrl+C`             | Cancel or stop        |
