# Week 1 — First Wins: GitHub, VS Code & the Terminal

> **Who this is for:** Everyone learning together — no prior experience needed.
> **OS:** Ubuntu Linux
> **Time:** ~1 hour per day, Monday to Friday
> **Goal by end of week:** You have a live GitHub profile, you know VS Code, and you can navigate your computer from the terminal.

---

## Overview

Week 1 focuses on getting comfortable with the core tools: GitHub, VS Code, and the terminal. Each day is scoped to one main outcome so it is easy to work through in order or revisit later.

## Daily plan

| Day                | Title                                   | Goal                                                                                |
| ------------------ | --------------------------------------- | ----------------------------------------------------------------------------------- |
| [Day 1](./day1.md) | Quick Wins: Feel Like a Developer       | Get a live GitHub profile and make a first public change online.                    |
| [Day 2](./day2.md) | Terminal Basics: Navigating Files       | Navigate folders and create files from the terminal without using the mouse.        |
| [Day 3](./day3.md) | VS Code Deep Dive                       | Learn the VS Code layout, install key extensions, and build a commands cheat sheet. |
| [Day 4](./day4.md) | File Permissions & Installing Tools     | Understand Linux permissions, install tools, and configure Git.                     |
| [Day 5](./day5.md) | Week 1 Review: Scavenger Hunt & Preview | Review the week's skills from memory and preview Git for Week 2.                    |

## Suggested flow

1. Start with [Day 1](./day1.md) and work in order through [Day 5](./day5.md).
2. Use [Day 3](./day3.md) to build the cheat sheet you will reuse in [Day 4](./day4.md) and [Day 5](./day5.md).
3. Return to [Day 5](./day5.md) at the end of the week to check what still needs practice.

## Week 1 quick reference

| Command              | What it does          |
| -------------------- | --------------------- |
| `pwd`                | Show current location |
| `ls`                 | List files in folder  |
| `ls -l`              | List with details     |
| `cd foldername`      | Enter a folder        |
| `cd ..`              | Go up one level       |
| `cd ~`               | Go to home folder     |
| `mkdir name`         | Create a folder       |
| `touch file.txt`     | Create empty file     |
| `cp a.txt b.txt`     | Copy a file           |
| `mv a.txt b.txt`     | Rename or move a file |
| `rm file.txt`        | Delete a file         |
| `tree folder/`       | Show folder tree      |
| `code .`             | Open VS Code here     |
| `sudo apt install X` | Install software X    |
| `Ctrl+Alt+T`         | Open terminal         |
| `Tab`                | Autocomplete          |
| `Ctrl+C`             | Cancel or stop        |
