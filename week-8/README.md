## Project ideas — pick one!

Choose a project that excites you. You do not need to be ambitious — a small project done well beats a big project that is broken.

| Difficulty | Project idea | What it does |
| ---------- | ------------ | ------------ |
| ⭐ Beginner | **Joke Bot with Memory** | Tells jokes, saves your favourites to a file, and never repeats one in the same session. |
| ⭐ Beginner | **Personal Quiz Maker** | Reads questions from a file, quizzes you, and saves your score history. |
| ⭐⭐ Intermediate | **AI Story Generator** | Uses the Claude API to generate a short story from a prompt you type. |
| ⭐⭐ Intermediate | **Recipe Suggester** | You say what ingredients you have; it suggests a meal. Reads recipes from a JSON file. |
| ⭐⭐ Intermediate | **Homework Explainer** | You paste in a question; the Claude API explains it in simple language. |
| ⭐⭐⭐ Advanced | **Mood Journal + AI Reflection** | You write a journal entry each day; the Claude API gives you a positive reflection and stores entries. |

> **Not sure?** Pick the Joke Bot or Quiz Maker. They are fun, fast, and feel great to demo.

## Week 8 quick reference

| Task | Command |
| ---- | ------- |
| Create project folder | `mkdir my-project && cd my-project` |
| Initialise git repo | `git init` |
| Create virtual environment | `python3 -m venv venv` |
| Activate virtual environment | `source venv/bin/activate` |
| Install a package | `pip install package-name` |
| Save your dependencies | `pip freeze > requirements.txt` |
| Stage and commit | `git add . && git commit -m "message"` |
| Push to GitHub | `git push origin main` |
| Run your program | `python3 main.py` |
