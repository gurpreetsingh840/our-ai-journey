# Our AI Journey

A structured 8-week course for learning GitHub, Git, Python, and AI from scratch on Ubuntu Linux.

This repository is organized as a week-by-week learning path with daily lesson files, weekly overviews, and space for future course content.

## Setup

Everything in the course uses free tools on Ubuntu Linux.

```bash
sudo snap install code --classic
sudo apt install git
sudo apt install python3 python3-pip
sudo apt install tree
```
