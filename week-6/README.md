# Week 6 — AI Concepts, Prompting & Ethics

> **Who this is for:** Everyone in the group — no special experience needed.
> **OS:** Ubuntu Linux
> **Time:** ~45–60 minutes per day, Monday to Friday
> **Goal by end of week:** You can explain what AI is, write good prompts, and think critically about how AI affects real people.

---

## Overview

This week we zoom out from coding and look at the bigger picture: **what is AI, how does it work, and is it being used fairly?**

You will not write much code this week. Instead, you will think, discuss, draw, experiment, and write. These skills are just as important as coding — the best AI builders are people who understand both the technology *and* the impact it has on the world.

By the end of Week 6 you will be ready for Week 7, where you write Python code that actually talks to an AI model.

## Key vocabulary

These are the important words you will hear all week. Read this table before Day 1 and come back to it whenever a word feels fuzzy.

| Word                  | Simple definition                                                                                                          |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **AI**                | Artificial Intelligence — software that can do tasks that normally need human thinking, like recognising faces or writing. |
| **Machine learning**  | A way of building AI where the program learns from examples instead of following hand-written rules.                       |
| **Training data**     | The collection of examples the AI learns from — could be millions of photos, sentences, or numbers.                       |
| **Model**             | The AI after it has been trained — a file full of patterns the computer learned from the training data.                    |
| **Prompt**            | The message or question you type to an AI to get a response.                                                               |
| **Inference**         | When the trained model makes a prediction or generates a response — the AI "thinking" in real time.                        |
| **Classification**    | Sorting something into a category (e.g. "this photo is a cat, not a dog").                                                 |
| **Pattern**           | A regularity that appears again and again in data (e.g. cats usually have pointy ears and whiskers).                       |
| **Bias**              | When an AI gives unfair results because its training data was unrepresentative or unfair.                                  |
| **Large language model (LLM)** | A type of AI trained on huge amounts of text — it can read and write in human language. Claude, ChatGPT, and Gemini are LLMs. |
| **Hallucination**     | When an AI confidently says something that is completely wrong or made up.                                                 |
| **Ethics**            | The study of what is right and wrong. AI ethics asks: is this AI being used fairly and safely?                             |
| **Deepfake**          | AI-generated video or audio that makes it look like someone said or did something they never did.                          |
| **Open source**       | Software whose code is shared publicly so anyone can read, use, or improve it.                                             |
