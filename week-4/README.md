# Week 4 — Python: Variables, Loops & Functions

> **Who this is for:** Everyone learning together — ages 10–14, no prior Python experience needed.
> **OS:** Ubuntu Linux with Python 3
> **Time:** ~45–60 minutes per day, Monday to Friday
> **Goal by end of week:** You can write real Python programs that store data, make decisions, repeat actions, and reuse code through functions.

---

## Overview

Week 4 is where the real coding begins. Python is one of the most popular programming languages in the world — and it was designed to be easy to read, which makes it perfect for learning.

By the end of this week you will have written five programs from scratch and understand the core ideas that every Python developer uses every single day.

## Daily plan

| Day                | Title                             | Goal                                                                              |
| ------------------ | --------------------------------- | --------------------------------------------------------------------------------- |
| [Day 1](./day1.md) | Hello Python: Variables & Types   | Run Python, use `print()`, and store information in variables.                    |
| [Day 2](./day2.md) | Strings & User Input              | Ask the user questions and build custom messages with f-strings.                  |
| [Day 3](./day3.md) | Making Decisions: if / elif / else | Write programs that choose what to do based on conditions.                        |
| [Day 4](./day4.md) | Loops: Doing Things Many Times    | Repeat actions using `for` and `while` loops, and control them with `break`.      |
| [Day 5](./day5.md) | Functions + Week 4 Review         | Package code into reusable functions and bring all week's skills together.        |

## Suggested flow

1. Start with [Day 1](./day1.md) — even five minutes of interactive Python builds confidence fast.
2. Each day's hands-on exercise builds on the last, so work through them in order.
3. On [Day 3](./day3.md) you build a guessing game — [Day 5](./day5.md) improves it using functions, so keep that file around.
4. Use [Day 5](./day5.md) at the end of the week to check what still needs practice before moving to Week 5.

## Week 4 quick reference

| Python syntax                       | What it does                                         |
| ----------------------------------- | ---------------------------------------------------- |
| `print("hello")`                    | Print text to the screen                             |
| `name = "Sara"`                     | Create a variable storing a string                   |
| `age = 12`                          | Create a variable storing an integer                 |
| `height = 1.5`                      | Create a variable storing a decimal (float)          |
| `likes_cats = True`                 | Create a variable storing True or False (bool)       |
| `type(x)`                           | Find out what type a value is                        |
| `input("Question: ")`               | Ask the user to type something                       |
| `int("42")`                         | Convert a string to an integer                       |
| `len("hello")`                      | Count the characters in a string (returns 5)         |
| `"hello".upper()`                   | Return the string in ALL CAPS                        |
| `"hello".lower()`                   | Return the string in all lowercase                   |
| `" hello ".strip()`                 | Remove spaces from both ends                         |
| `f"Hi, {name}!"`                    | Build a string that includes a variable              |
| `if x > 5:`                         | Do something only if condition is True               |
| `elif x == 5:`                      | Otherwise, check another condition                   |
| `else:`                             | Do this if none of the above matched                 |
| `==  !=  >  <  >=  <=`              | Comparison operators (equal, not equal, greater, …)  |
| `and  or  not`                      | Combine conditions                                   |
| `for item in list:`                 | Loop over every item in a list                       |
| `for i in range(10):`               | Loop with a counter from 0 to 9                      |
| `while condition:`                  | Keep looping as long as condition is True            |
| `break`                             | Exit a loop immediately                              |
| `continue`                          | Skip the rest of this loop step, go to the next      |
| `def greet(name):`                  | Define a function called `greet` with one parameter  |
| `return value`                      | Send a result back from a function                   |
| `python3 hello.py`                  | Run a Python file in the terminal                    |
| `python3`                           | Open Python's interactive mode in the terminal       |
